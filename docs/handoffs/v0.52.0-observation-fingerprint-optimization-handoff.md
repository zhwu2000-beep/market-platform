# v0.52.0 Observation Fingerprint Optimization Handoff

## Release Status

Implementation is complete on
`feature/v0.52.0-observation-fingerprint-optimization`, remains uncommitted, and
is unreleased. Package version remains `0.1.0`.

## Scope and Contract

V0.52.0 optimizes preparation of existing Historical Replay observation
fingerprints without changing their schema, payload, byte stream, or digest.

The legacy top-level payload contains `as_of`, `interval`, `provider`, `rows`, and
`symbol`. Every ordered row contains `close`, `high`, `low`, `open`, `provider`,
`symbol`, `timestamp`, and `volume`. JSON remains compact, sorted, ASCII-escaped,
and UTF-8 encoded for lowercase prefixed SHA-256. Row numerics remain
`repr(float(value))`; `0.0` and `-0.0` intentionally remain distinct.

Signals, structures, price facts, methodology, extra provider columns, and
dataset identity remain excluded.

## Public API

- `HistoricalObservationFingerprintPrecompute`;
- `prepare_historical_observation_fingerprints(series, positions, *, interval)`.

`HistoricalObservationFingerprintPrecompute` is factory-constructed only. Direct
construction raises `TypeError` and identifies
`prepare_historical_observation_fingerprints()` as the supported boundary.

The existing validated-prefix builder has one additive optional
`fingerprint_precompute` keyword. Raw construction, prefix construction without a
precompute, Replay service signatures, and CLI behavior remain unchanged.

## Preparation and Operation Counts

For requested positions, preparation:

1. validates a strictly increasing nonempty position tuple;
2. projects and encodes rows once through the maximum requested position;
3. builds one transient comma-separated row-byte stream and offsets;
4. hashes the exact legacy header, applicable row-stream view, and suffix for each
   requested position;
5. retains only final strings and immutable binding facts.

For N full-prefix steps beginning at zero:

- prior row projections/encodings: `N(N+1)/2`;
- optimized row projections/encodings: `N`;
- precompute constructions: one;
- bound lookups: one per step;
- optimized Replay fallback calculations: zero.

For a later evaluation window, row preparation is `maximum position + 1`, because
all retained context rows participate. Total SHA-256 input remains O(N²); this
release makes no complete linear-time claim.

## Binding and Fallback

The precompute binds to the exact source `HistoricalPriceSeries` instance,
symbol, interval, provider, source row count, prepared position, prefix length,
endpoint, and observation `as_of`. The source content fingerprint is diagnostic
only. The private source reference is excluded from representation, equality,
hashing, serialization, Replay output, and Artifact bytes.

The standalone fallback and optimized paths share exact row projection, row JSON,
envelope, and SHA-256 helpers. No raw fingerprint or trust/skip flag is accepted.

## Limitations and Non-Goals

Exact legacy bytes prevent one rolling SHA state because changing `as_of` occurs
before `rows`. Hash input therefore remains cumulative. No fingerprint migration,
prefix/Merkle identity, provider-neutral identity, signed-zero normalization,
global/disk cache, persistence, parallelism, CLI, UI, workflow, Agent integration,
or unrelated Replay optimization is included.
