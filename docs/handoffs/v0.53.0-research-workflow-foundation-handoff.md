## Scope

V0.53.0 adds a synchronous deterministic historical Replay composition boundary.
It coexists with the unchanged asynchronous, provider-facing `ResearchWorkflow`
and `DefaultResearchWorkflow`.

One workflow owns one canonical `HistoricalPriceSeries`, one baseline member,
zero or more ordered candidate members, and three explicit `SoftwareRevision`
values. It composes existing Replay execution, Replay Artifact construction, and
Historical Replay Experiment creation without reproducing their logic.

## Fixed Policy and Error Boundary

Zero candidates produce a successful Replay-only result. Candidate order and
duplicate positions are significant. A baseline Replay failure skips Artifact,
candidate, and optional Experiment steps. After baseline success, candidate
Replays continue independently; successful Artifacts remain at their requested
positions. Any candidate failure prevents Experiment creation. The requested set
is never reduced.

The exact captured exception tuple is:

```python
(StrategyRunnerError,)
```

`StrategyRunnerError` is the existing dedicated strategy invocation/contract
failure boundary. `ValueError`, `TypeError`, `RuntimeError`, `AssertionError`,
`KeyboardInterrupt`, `SystemExit`, Artifact errors, Experiment errors, and other
defects propagate.

## Identity and Invariants

Member identity includes Replay specification, re-derivable state-model identity
and configuration fingerprint, structure derivation, and ordered
`StrategyInstance` identities and configuration fingerprints. Ordinary Replay
may continue accepting broader `Strategy` and `MarketStateModel` implementations;
the historical workflow deliberately accepts only the deterministic subset whose
complete behavior identity can be re-derived from the runtime object.

`HistoricalReplayResearchStateModelInstance` extends the state-model behavior
boundary with a read-only `configuration_fingerprint`. `None` is reserved for a
truly stateless model. Strategy and state-model implementers must include every
behavior-affecting value in their configuration identity. Object identity,
`repr`, arbitrary serialization, and filesystem state are never identity inputs.
Workflow identity includes source content, symbol, interval, provider, indexed
members, fixed policy, and separate Replay, comparison, and workflow revisions.

Runtime strategy/state identities are captured at member construction and
re-derived immediately before and after every baseline and candidate execution,
including duplicate member positions. Mutation produces an invariant failure
outside the captured Replay boundary. Produced provenance is then checked before Artifact
construction for specification, retained dataset, provider, context, Replay
revision, state model, structure derivation, and ordered strategies.

Terminal status and steps are canonical:

- `SUCCEEDED`: baseline exists; all candidates succeeded; Experiment exists iff
  candidates were requested;
- `PARTIALLY_SUCCEEDED`: baseline exists; one or more candidates failed; no
  candidate is skipped; Experiment absent;
- `FAILED`: baseline absent; every dependent step skipped.

Result identity includes ordered step and candidate outcomes, run/result
fingerprints, stable failure/skip codes, and optional Experiment/comparison
fingerprints. Artifact checksums, bytes, paths, timestamps, durations, tracebacks,
messages, rendering, and object identity are excluded.

## Compatibility and Non-Goals

Successful Artifacts and Experiments are complete existing production objects.
The workflow performs no persistence, CLI invocation, provider access, Replay
logic, Artifact codec work, or comparison logic. Existing Research, Replay,
observation, Artifact, Experiment, CLI, benchmark, and package-version contracts
remain unchanged.

Deferred: durable Workflow Artifact, manifest/locator semantics, workflow
save/load, CLI, async execution, parallelism, retries, cancellation, generic DAG,
scheduler, parameter grids, optimization, portfolio or financial metrics, UI,
Agent, and database/cloud storage. Workloads are trusted, local, and synchronous.
