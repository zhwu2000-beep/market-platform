## Public API

`market_platform.execution_planning` exports exactly:

- enum `PositionDeltaAction`: `buy`, `sell`, `no_action`;
- model `PositionTargetTranslation`;
- function `translate_position_target()`;
- errors `ExecutionPlanningDomainError`, `ExecutionPlanningValidationError`,
  `ExecutionPlanningCorrespondenceError`, and
  `ExecutionPlanningUnavailableError`;
- schema constant `POSITION_TARGET_TRANSLATION_SCHEMA`.

The only new fingerprint family is `position_target_translation/v1`.

## Inputs and Gates

The function requires an exact `RiskEvaluationContext`, its exactly corresponding
canonical `RiskDecision`, and an exact canonical UTC `plan_as_of`. It reconstructs
the complete context through the public risk constructor, calls
`evaluate_structural_risk()`, and compares the supplied decision with the result.
Only `approved` with empty findings, a common account, and complete-account
position/open-order coverage proceeds. `plan_as_of` must exactly equal context
and decision `evaluation_as_of`.

Canonical non-approved decisions, different planning times, target open-order
exposure, oversized released targets, and unrepresentable output are reported as
`ExecutionPlanningUnavailableError`. Malformed direct input uses validation
errors; fabricated retained state uses correspondence errors.

## Translation Contract

- long `U` -> signed target `+U`;
- flat -> canonical positive zero;
- short `U` -> signed target `-U`;
- matching position row -> exact signed current quantity;
- absent row under complete-account coverage -> positive zero;
- delta -> exact target minus current;
- positive delta -> `buy`;
- negative delta -> `sell`;
- zero delta -> an auditable `no_action` translation.

Any exact target-instrument exposure blocks. No exposure is summed, netted, or
directionally interpreted; unrelated exposure is ignored.

## Bounds and Arithmetic

Target and current operands are finite exact `Decimal` values with at most 128
digit characters, 64 fractional digits, and 256 fixed-point characters. Delta
permits 129 digit characters and 64 fractional digits. Fixed-point formatting is
bounded before materialization, uses no float or scientific notation, and never
emits negative zero. Integer coefficient/scale subtraction is independent of the
ambient Decimal context.

No price multiplication, notional, cash comparison, buying power, FX, margin,
leverage, commission, rounding, lot sizing, or open-order arithmetic exists.

## Bounded Projection

The public projection contains schema, action, risk context/decision/intent
fingerprints, canonical instrument ID and descriptor fingerprint, account
fingerprint, position/open-order snapshot fingerprints, exact plan time,
target/current/delta strings, and translation fingerprint. It retains no source
context, decision, intent, resolution, snapshot, row, policy, or finding.

The factory privately retains an independent canonical primitive constructor
tuple, identity-bound to its original object with a private token. These values
are unprojected, unfingerprinted, unversioned, and non-cryptographic. Validation
rejects deleted slots, equal or forged tuple replacement, synchronized semantic
mutation, impossible arithmetic/action, and recomputed fingerprints over false
state.

## Retained Snapshot Structure Preflight

Before public risk-context reconstruction, exact retained structure is required:

- cash header: `account`, `source`, `as_of`, `balances`, `schema_version`,
  `fingerprint`; `CashBalance`: `currency`, `amount`;
- position header: `account`, `source`, `as_of`, `positions`, `schema_version`,
  `fingerprint`; `PositionRecord`: `instrument_id`, `quantity`;
- open-order header: `account`, `source`, `as_of`, `exposures`,
  `schema_version`, `fingerprint`; `OpenOrderExposure`: `external_order_id`,
  `instrument_id`, `remaining_quantity`;
- quote header: `source`, `as_of`, `quotes`, `schema_version`, `fingerprint`;
  `MarketQuote`: `instrument_id`, `bid`, `ask`, `last`.

Snapshot and row types are exact and each retained collection must be an exact
built-in tuple. The preflight checks structure and slot presence only. Released
constructors still own all value and correspondence semantics. Missing or
fabricated retained structure becomes `ExecutionPlanningCorrespondenceError`;
unexpected programming exceptions are not broadly translated.
