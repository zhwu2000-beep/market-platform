## Public API

`market_platform.execution_planning` preserves all eight v0.60 exports and adds exactly:

- `BROKER_NEUTRAL_EXECUTION_INSTRUCTION_SCHEMA`;
- `ExecutionInstructionSide` with `buy` and `sell` only;
- `BrokerNeutralExecutionInstruction`;
- `derive_broker_neutral_execution_instruction()`.

The new schema and fingerprint family are exactly `broker_neutral_execution_instruction/v1`. Existing execution-planning errors are reused unchanged.

## Derivation Contract

The function accepts only an exact canonical `PositionTargetTranslation` and invokes its public context-free validation. `buy` and `sell` translations produce exactly one instruction. `no_action` returns exactly `None`, creates no instruction identity, and leaves the translation as the audit artifact.

Instruction quantity is the strictly positive absolute delta. Decimal tuple sign removal preserves coefficient and exponent without ambient-context arithmetic. Bounds remain 129 digit characters, 64 fractional digits, and 258 fixed-point characters.

## Public Model

The factory-owned frozen/slotted instruction exposes only:

- side;
- positive `Decimal` quantity;
- source translation fingerprint;
- canonical instrument ID and descriptor fingerprint;
- account fingerprint;
- exact copied `plan_as_of`;
- derived schema and fingerprint.

The JSON-safe projection emits the quantity as canonical fixed-point text. It contains no source object, upstream context/decision/snapshot fingerprints, order style, broker field, or metadata.

## Retained-State Correspondence

The exact validated source translation is retained privately. Independent primitive constructor state is identity-bound to its original tuple and protected by a guarded token. Serialization verifies source translation validity, side/action, quantity/absolute-delta, copied evidence, schema, and fingerprint. Retained state is private, unprojected, unfingerprinted, unversioned, and non-cryptographic.

## Temporal and Authority Boundary

The instruction copies translation `plan_as_of` exactly and adds no clock, later time, expiry, or revalidation helper. It is a non-executable proposal, not an order specification, permission to trade or short, financial/compliance/human/broker approval, or submission authority.
