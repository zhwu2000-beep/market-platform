## Scope

v0.47.0 establishes a public canonical boundary between raw historical price
DataFrames, replay, and historical observation construction:

- validate and normalize a complete historical series once;
- represent replay prefixes with immutable positional objects;
- avoid default per-step DataFrame prefix copies and full-prefix normalization;
- retain explicit DataFrame compatibility for raw public APIs and custom structure
  services;
- preserve historical observation fingerprints and replay serialization;
- correct replay benchmark instrumentation so it follows the optimized path.

## Architecture Decisions

- `market_platform.data.historical` owns canonical historical-price validation.
- `HistoricalPriceSeries` owns the defensive normalized frame and series identity.
- `HistoricalPricePrefix` owns inclusive positional semantics and the endpoint
  `as_of`.
- Prefix `as_of` is the final included historical-data timestamp. Observation
  `as_of` is the evaluation time and may be later, subject to
  `HistoricalPricePrefix.as_of <= MarketObservation` evaluation `as_of`.
- Replay remains an application workflow and consumes the public prefix-aware
  observation builder.
- Observation owns observation metadata, snapshot validation, identity, price
  facts, provenance, fingerprinting, and final model construction.
- Raw DataFrame observation calls adapt through the same canonical prefix path.
- Custom structure services receive defensive prefix DataFrame materializations
  without exposing the canonical owner.

See `docs/adr/0004-canonical-historical-input.md`.

## Compatibility Guarantees

- Existing DataFrame observation and replay entry points remain available.
- Inclusive replay start/end selection remains unchanged.
- Signal and structure precompute retain the full supplied-frame context.
- Implicit default, explicit default-equivalent, and reference-compatible custom
  structure services produce identical replay outputs where analytically
  equivalent.
- State and strategy continue to receive the same observation identity and
  fingerprint.
- The deterministic 100/300/500-bar benchmark result fingerprints exactly match
  the committed v0.46.0 report.

The raw DataFrame observation adapter intentionally applies replay-grade
positive-OHLC and nonnegative-volume validation. v0.46.0 temporal compatibility
is retained: the observation evaluation `as_of` may be later than the final
canonical prefix timestamp. Future rows retain the existing
`price prefix must not contain timestamps later than as_of` rejection.

## Benchmark

Command:

```powershell
uv run python scripts\benchmark_replay.py `
  --bars 100 300 500 `
  --runs 3 `
  --warmups 1 `
  --format json `
  --output W:\AI\Temp\v0.47.0-canonical-historical-input-final.json
```

| Bars | Production | Instrumented | Canonical normalizations | Prefix objects | Prefix DataFrames | Fingerprint rows |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 100 | 209.060 ms | 221.375 ms | 1 | 100 | 0 | 5,050 |
| 300 | 1,254.499 ms | 1,323.430 ms | 1 | 300 | 0 | 45,150 |
| 500 | 2,883.975 ms | 2,943.299 ms | 1 | 500 | 0 | 125,250 |

Every scenario reported exact production/instrumented `to_dict()` parity and stable
output. Result fingerprints matched v0.46.0.

The temporal-compatibility correction was rerun with the same 100/300/500-bar
scenario. It preserved those result fingerprints, one canonical normalization and
one full-series materialization per scenario, one prefix object per step, and zero
per-step prefix DataFrame materializations or normalizations. Timing variation
between runs is not interpreted as an improvement or regression.

The committed v0.46.0 report recorded production medians of 603.150 ms,
2,831.507 ms, and 4,916.412 ms. The new medians are indicative improvements of
approximately 65.3%, 55.7%, and 41.3%, respectively. These are separate benchmark
runs, so they are not a controlled performance guarantee.

At 500 bars, observation construction measured 2,113.857 ms and fingerprint-row
traversal measured 1,529.392 ms. Fingerprint projection is now the dominant
remaining observation cost.

## Current Limitations

- Each fingerprint still traverses every row in its prefix, producing cumulative
  quadratic row projection across a full replay.
- Signal and structure precompute still consume a single defensive full-series
  DataFrame materialization.
- Canonical ownership is in-memory only; no dataset versioning or persistence was
  added.
- Existing provider normalization remains separate from replay-grade canonical
  historical validation.

## Explicit Non-Goals

- Replay manifests or persistence.
- Research migration.
- Portfolio, risk, execution, accounting, or valuation concepts.
- Event buses, microservices, generalized repositories, or dataset frameworks.
- Package-version, release-tag, merge, or push changes.
