## 8. Assessment authority and locking

Canonical immutable built-in bytes are committed authority. Typed staging and
public results confer no authority. The Assessment history owner and
Interpretation publisher are pinned; there is no Assessment `_history`
compatibility alias. Lock selection and authentication use the same pinned
Interpretation publisher.

The exact ten-lock order is:

```text
construction
→ validation
→ freshness
→ admission
→ validity
→ qualification
→ bridge
→ technical
→ governed Interpretation
→ governed Assessment
```

The original pinned Assessment owner is tenth/final.

## 9. Public execute workflow

Released entry point on
`PolygonCompletedDailyProductionAssessmentApplicationService`:

```python
execute(request)
```

- Require the exact `PolygonCompletedDailyAssessmentRequest` type and
  defensively detach the request.
- Use canonical UTC clocks with temporal ordering `I <= S <= C <= R`:
  Interpretation availability, Assessment start, completion, and publication
  availability, respectively.
- Perform one Assessment semantic execution, independent validation, and
  repeated exact source authentication.
- Allocate a unique execution ID after successful preparation/completion.
- Prepare canonical byte publication and a detached public result, preserving
  original-owner pending cleanup, failure atomicity, and a single authoritative
  append.

**Final publication seal:** all fallible local projection, codec,
reconstruction, copy, graph, history validation, clock, and allocation work
occurs before the final exact Interpretation source/support seal. After a
successful seal only direct identity/scalar checks, original-owner pending
cleanup, authoritative state advancement, and return remain.

## 10. Public history workflow

Released entry point on the same application service:

```python
get_result_history_as_of(
    artifact_reference,
    *,
    knowledge_as_of,
)
```

- Require the exact `GovernedTechnicalArtifactReference`. Normalize
  `knowledge_as_of` through the released timestamp convention to canonical UTC;
  timezone-aware non-UTC inputs are accepted and normalized, while invalid
  timestamp inputs fail as `TEMPORAL_FAILURE`. No execution clock is used.
- Acquire the ten locks once.
- Authenticate the **COMPLETE** committed Assessment history before filtering,
  including every retained source Interpretation publication and independent
  retained Assessment validation.
- A committed source that is unavailable maps to `HISTORY_INVALID`
  (`history_incomplete_or_corrupt`).
- Apply visibility only afterward: exact artifact equality **AND**
  `available_at <= knowledge_as_of`. The cutoff is inclusive.
- Return results in history-sequence order through fresh caller-owned graph
  reconstruction, without authority mutation.

**Final read seal:** all copy, projection, codec, graph, domain, and history
validation completes before final complete source/support authentication,
including sources of invisible retained occurrences. After the final seal only
direct identity checks and return remain.

## 11. Concurrency / atomicity

Execute and history read serialize through the original pinned Assessment
owner. Readers observe complete pre-commit or post-commit state only.
Pending/staged state is never public authority. Failed publication appends
nothing, leaves committed bytes unchanged, and leaves the sequence reusable.
