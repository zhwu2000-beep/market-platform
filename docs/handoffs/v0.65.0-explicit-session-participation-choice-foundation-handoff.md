`SessionParticipation` has exactly two members in order:

1. `REGULAR_ONLY = regular_only`
2. `REGULAR_AND_EXTENDED = regular_and_extended`

There is no extended-only, all-eligible, broker-default, unspecified, default,
unknown, or no-action member. Absence never implies either choice.

`SessionParticipationChoice` is a frozen, slotted, timeless, bounded,
caller-authored value with exact fields `session_participation`, `schema_version`,
and `fingerprint`. Construction requires the exact enum runtime type. Its schema is
`session_participation_choice/v1`; its fingerprint covers exactly the schema and
canonical lowercase value; its exact three-key projection is JSON-safe.

Retained enum state requires the exact enum type. Retained schema and fingerprint
require exact built-in strings before equality. Wrong values, equality-spoofing
objects, string subclasses, stale enum/fingerprint combinations, and deleted slots
raise `ExecutionPlanningCorrespondenceError`.

## Semantic boundary

`REGULAR_ONLY` requests participation only in the downstream-resolved applicable
regular session. `REGULAR_AND_EXTENDED` requests that plus downstream-resolved,
eligible non-regular continuous sessions. Neither value establishes exact windows,
timezone/calendar behavior, current-open state, auctions, overnight access,
broker support, routing, acceptance, or execution.

The choice has no token, constructor-state tuple, identity binding, retained
source, or factory. It retains no instrument, venue, style, price, TIF,
instruction, account, timestamp, calendar, capability, authorization, broker,
submission, or lifecycle state. It is non-executable and unauthorized.

No `BrokerNeutralOrderSpecification` exists in this release. A future constructor
will bind instruction, canonical instrument, style, explicit conditional price,
TIF, and session participation. MARKET will pass explicit `None` for price; LIMIT
will pass exactly one price choice. Correspondence, compatibility, capability,
authorization, mapping, submission, and lifecycle remain future.
